# Waylaw

A fast and lightweight application launcher for Wayland/Hyprland, built with Rust and GTK4.

## Installation (Manual)

Since the AUR registration is temporarily closed, you can install Waylaw by downloading the pre-compiled binary or building it from source.

### Option 1: Download the binary (Recommended)
1. Go to the [Releases](https://github.com/DuckCosmos/waylaw/releases) page.
2. Download the latest `.tar.gz` file.
3. Extract it and move the binary to your local bin directory:
   ```bash
   tar -xzf waylaw-*.tar.gz
   mkdir -p ~/.local/bin
   mv waylaw ~/.local/bin/
   chmod +x ~/.local/bin/waylaw
